Google Tasks Filter

Privacy policy

Last updated: October 15, 2026

Purpose and local processing

Google Tasks Filter reads the titles, identifiers and displayed list names of loaded task rows on tasks.google.com to filter tasks or display a collected results list. Task descriptions are not searched. Processing happens temporarily in your browser. The developer does not receive your task content.

Search text and retention

Search terms, the selected view and result records stay in memory in the current tab. The extension does not write task data or search text to extension storage, localStorage, sessionStorage, cookies or remote databases. Reset clears the search field. Closing the search bar, including with Escape, retains the query and view in memory in the current tab. Reloading the page initializes an empty search.

Network and account access

The extension makes no network requests and has no backend, analytics, advertising or telemetry. It does not ask for your Google password, access tokens or an additional account authorization. Google Tasks itself continues to communicate with Google using your existing session.

Page access and task changes

The content script runs only on https://tasks.google.com/*. It adds a search icon, header search field and an overlaid dropdown for controls and results, hides non-matching rows in Filter mode, and leaves the Google task view visible in Results mode. Activating a result scrolls to and focuses its original row with highlighting for eight seconds or until Escape is pressed. Matching original rows are subtly outlined while search is open. It does not create, edit, complete or delete stored tasks. Normal task actions remain Google Tasks actions.
