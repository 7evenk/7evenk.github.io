Album Sorter for OneDrive

Privacy policy

Last updated: September 14, 2026

Album Sorter for OneDrive is an independent Chrome extension by Sven Knoerzer (7evenk). It sorts and filters the overview of your own albums in OneDrive Personal by album name. This policy explains the extension’s data handling and how to contact its developer.

Album data processed in your browser

The extension reads OneDrive’s album-list response, including album names, identifiers and the other fields supplied in that response, such as thumbnail references. It may request further pages of the same list so it can sort and filter the collection before it is displayed. Album records are handled temporarily in browser memory and are not persistently stored by the extension.

Connections to Microsoft

The required read requests go to Microsoft’s OneDrive service over HTTPS using your existing OneDrive session. The extension has no separate backend and does not send album records, photos, credentials, usage statistics or diagnostic reports to the developer or additional services. It does not change photos or server-side album records. It does not ask you to provide a password or store your sign-in credentials.

The setting stored on your device

Only your selected order—Default, A–Z or Z–A—is stored in chrome.storage.local in the current Chrome profile. It remains until changed or the extension’s storage is removed. It is not synchronized through chrome.storage.sync. Uninstalling the extension removes its local extension storage.

Search text in this tab

When you apply a name filter, the extension stores the search text in sessionStorage on the OneDrive page for the current tab. This is separate from the extension storage described above. It keeps the filter available after reloads and navigation in that tab. OneDrive page scripts can access this storage. The extension does not add the search text to network requests, send it to the developer or synchronize it between devices.

Clear removes the stored search text. Browser session restoration may retain it, and duplicating a tab may copy it. The search text is not account-specific and can remain if you switch OneDrive accounts in the same tab. Uninstalling the extension does not itself clear this separate page storage. Album response records are never saved in either storage area. This name-filter behavior applies from version 0.2.0.

Permissions and purpose

The storage permission retains your sorting preference. Content-script access to https://onedrive.live.com/* lets the extension handle navigation within OneDrive’s single-page application and display its controls. Album processing is restricted to the supported personal album overview and its read-only album-list request.

Limited use

The extension’s use of information complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide album sorting and name filtering. It is not sold, used for advertising, transferred for unrelated purposes, or used to determine creditworthiness or for lending. The developer does not receive or review your album data. The extension includes no telemetry, advertising, payments or license checks.

Support messages

Support is provided through the Chrome Web Store. If you submit a question or issue, the information you provide is used to respond and troubleshoot the issue. Support posts may be public and are handled through Google’s service. Do not post credentials, private album exports or personal photos. For confidential inquiries, use the developer contact details shown in the store rather than a public support post.

This website and other providers

This website is hosted on GitHub Pages. GitHub may process connection information, including IP addresses, to operate and secure its service; see the GitHub Privacy Statement. These pages add no analytics, tracking scripts or cookies. Microsoft OneDrive and Google Chrome operate independently under their own privacy policies; this policy describes the extension and its support contact.
