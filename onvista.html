Frequently asked

Good to know.

What does the extension display?

The detected course URL plus the date and course paths needed for historical JSON data in Portfolio Performance.

Does the selected exchange matter?

Yes. The displayed course data reflects the exchange selected on OnVista.

Does it need to stay enabled?

No. Use the switch to enable it only when needed.

Is personal data transferred?

No. The Chrome Web Store disclosure states that no user data is collected or used.
